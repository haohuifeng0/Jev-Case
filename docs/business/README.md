# Business Offer and Positioning

Jev Case helps an enterprise evaluate one bounded AI Agent decision before considering broader implementation. The commercial path starts with a fixed-scope assessment and proceeds, only when supported by evidence, to a proof of concept for one decision node.

The offer is suitable when a named owner can provide a decision question, representative lawfully shareable examples, and reviewable acceptance evidence. It is not a production implementation, managed service, legal or compliance review, or broad transformation program.

`../../src/data/business.json` is the authoritative source for offer prices, timelines, scope, policies, and metric definitions. Prose in these documents is a human-readable summary and must be checked against that file.
